# Step 4: 输出与保存

**优先级**: ⭐⭐ | **必做**: 是

---

## 目标

将解析后的内容按用户需求格式化输出，并可选择保存到文件。

---

## 输出方式

### 方式 1: 直接输出到对话

默认方式，适合预览和快速使用。

```markdown
# Claude Code 2.1 发布：30+ 新功能详解

**来源**: 机器之心 | **作者**: 李四 | **时间**: 2026-01-24

Claude 今日发布了 Claude Code 2.1 版本，带来了 30 多项新功能和改进...

[完整内容]
```

### 方式 2: 保存为 Markdown 文件

```markdown
# 保存文章

文件路径: `mp-wechat/_materials/news/2026-01-24-claude-code-2.1.md`
```

### 方式 3: 添加到素材库

```markdown
# 添加到个人素材库

文件路径: `mp-wechat/_personal_materials/news-clips.md`
```

---

## 文件命名规范

### 新闻文章

```
格式: YYYY-MM-DD-{关键词}-{来源}.md
示例: 2026-01-24-claude-code-2.1-jiqizhixin.md
```

### 素材片段

```
格式: {类别}-{简短描述}.md
示例: news-clips-ai-tools.md
```

---

## 保存位置建议

### 临时文件

```
mp-wechat/_drafts/_temp/
```

### 新闻素材

```
mp-wechat/_personal_materials/news/
```

### 参考文章

```
mp-wechat/_writing_reference/
```

## 批量爬取

当用户请求批量爬取时：

### 流程

1. 获取文章列表 URL
2. 逐个爬取内容
3. 汇总输出或批量保存

### 输出格式

```markdown
# 批量爬取结果

来源: 量子位
日期: 2026-01-24
文章数: 5

---

## 1. [文章标题]

[摘要内容]

---

## 2. [文章标题]

[摘要内容]

...
```

## 错误恢复

如保存失败：

```markdown
⚠️ 文件保存失败

可能原因:
- 目录不存在
- 权限不足
- 磁盘空间不足

已尝试:
1. 创建目录
2. 重新写入

建议:
- 检查文件系统
- 尝试其他保存位置
- 直接复制到剪贴板
```
