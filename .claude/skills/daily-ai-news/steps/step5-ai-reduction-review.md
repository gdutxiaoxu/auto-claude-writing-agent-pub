# Step 5: 降AI味审校

**优先级**: ⭐⭐⭐ | **必做**: 是

> **这是整个流程中最关键的一步！**

---

## 审校流程

```
v1初稿 → 第一遍（内容审校）→ v2
       → 第二遍（风格审校）→ v3
       → 第三遍（细节打磨）→ final
```

---

## 第一遍：内容审校

**检查清单**:
- [ ] **事实准确**: 新闻来源、时间、数据正确
- [ ] **逻辑清晰**: 观点明确，推理合理
- [ ] **无编造**: 所有信息都真实可验证
- [ ] **段落迷你论点**: 每段都有明确论点

**段落迷你论点检查** ⭐:
1. 在每段旁边用一句话标注该段的核心论点
2. 如果标不出来 → 段落需要重写
3. 串联测试：把所有迷你论点串起来，应该形成清晰的逻辑链条

**操作**: 列出问题 → 逐一修改 → 保存为 v2

---

## 第二遍：风格审校（AI味降重）⭐⭐⭐

**目标**: 去掉AI味，增加人味

### AI味特征清单

**1. 删除套话**
- ❌ "在当今时代"
- ❌ "综上所述"
- ❌ "值得注意的是"
- ❌ "需要强调的是"
- ❌ "总而言之"

**2. 拆解AI句式**
- ❌ "不是…而是…"连续出现
- ❌ "不仅…还…"重复使用
- ❌ 三段论过于工整

**3. 替换书面词汇**
- ❌ "显著提升" → ✅ 具体数字
- ❌ "充分利用" → ✅ "用好"
- ❌ "进行操作" → ✅ 直接用动词
- ❌ "相关工作" → ✅ 具体说做什么

**4. 改成口语化**
- ❌ "通过XX方式进行XX" → ✅ 直接说怎么做
- ❌ 过于正式的表达 → ✅ 像说话一样写

**5. 加入真实细节**
- ❌ 抽象表达 → ✅ 具体数字/案例
- ❌ "效率提升" → ✅ "每个项目省3-5小时"

**6. 加入个人态度**
- ❌ 中立客观 → ✅ 明确观点
- ❌ "可能会" → ✅ "我觉得"

### 常见改写示例

❌ **AI味**:
```
在当今AI技术飞速发展的时代，编程工具也在不断进化。
通过充分利用Claude Code的能力，可以显著提升开发效率。
```

✅ **人味**:
```
Claude Code出了。我用了两周，确实比Cursor好用。
用好Claude Code，你的开发速度能快不少。我测下来，平均每个项目省3-5小时。
```

**操作**: 逐段检查 → 标记AI味 → 改写 → 保存为 v3

## 第三遍：细节打磨

### 1. 句子长度与节奏 ⭐⭐⭐

- ✅ 15-25字为主，但**必须有变化**
- ✅ 短句（5-10字）+ 中句（15-25字）+ 长句（25-35字）交替
- ❌ 避免连续3句以上同样长度

**句子节奏检查法**:
1. 标记每句话的字数
2. 观察分布：是否有变化？
3. **找出单调区域**（连续5句都是20字左右）
4. **调整**：插入短句或长句打破单调
5. **大声朗读**：感受呼吸和节奏

**示例改写**:

❌ **单调版本**（都是中等长度）:
```
周五早上我发了一条推文。(11字)
中午看了一眼数据很不错。(11字)
晚上再看的时候已经爆了。(11字)
我感到非常震惊和意外。(10字)
```

✅ **有节奏版本**:
```
周五早上，我在X上发了一条关于AI换脸的推文。(20字-中)
中午看了一眼，1万多浏览，还不错。(15字-中)
到晚上再看，50万了。(9字-短) ← 短句制造停顿
我愣了。(3字-极短) ← 极短句制造冲击
这才过了几个小时？(8字-短)
到周日晚上，这条推文的曝光量突破了500万。(31字-长) ← 长句展开
```

### 2. 段落长度
- ✅ 手机屏幕3-5行
- ❌ 不超过7行

### 3. 标点自然
- ✅ 多用句号（制造停顿）
- ❌ 少用逗号连接长句

### 4. 多巴胺密度检查 ⭐
- 用 (1) (2) (3) 标记"有意思"的句子
- 标准：这句话让你觉得"哦，有意思"、"这个洞见不错"
- **每段至少1个多巴胺点**

### 5. 微幽默检查
- 每200字至少有1个微幽默点
- 标记：🙂 = 微幽默，😐 = 无感
- 如果连续500字都是 😐，需要注入幽默

### 最终检查
- **大声朗读全文**（最重要！）
- 感受是否自然
- 是否像用户本人在说话
- 节奏是否有变化

**保存**: 最终版保存为 `YYYY-MM-DD-ai-news-final.md`

---

## 审校技巧总结

1. **内容审校**: 确保真实、准确、逻辑清晰
2. **风格审校**: 去掉AI味，增加人味
3. **细节打磨**: 创造节奏，增加多巴胺点

**记住**: 三遍审校是降AI味的核心，绝不能省略！
