## 🎯 核心原则

### 1. 真实性优先
- 所有新闻必须来自可靠来源
- 必须验证信息准确性
- 不确定的信息标注"待确认"

### 2. 风格一致性
- 必须学习用户已有文章风格
- 避免通用AI腔调
- 保持用户的表达习惯

### 3. Think Aloud
- 关键决策时说明思考过程
- 新闻选择时说明理由
- 风格调整时说明依据

### 4. 用户确认
- 选定3条新闻后，提供简要说明
- 等待用户确认后再开始写作
- 风格调整时征求用户意见

## 📊 输出格式

**文章结构**:
- 标题（吸引人但不标题党）
- 开头（日期+引入）
- 01/02/03 编号（3条新闻）
- 每条包含：标题+内容+个人观点
- 🛠️ 今日推荐（可选）
- 明天见（简洁结尾）

**字数**: 1500-2000字
**配图**: 不需要（新闻类文章）

## 💡 使用示例

**用户触发**:
> "生成今日AI编程新闻"

**Claude执行**:
1. 使用 DuckSearch MCP 搜索今日新闻（优先）或 WebReader MCP 爬取内容
2. 读取用户已有新闻文章学习风格
3. 选择 Top 3 新闻并说明理由
4. 等待用户确认

7. 输出最终文章

## 📞 注意事项

- 新闻必须是**今日**或**近24小时**的内容
- 优先选择**AI编程相关**的高质量内容
- 避免**纯营销**或**无实质内容**的新闻
- 每条新闻都要加入**个人观点**，不是简单转发
