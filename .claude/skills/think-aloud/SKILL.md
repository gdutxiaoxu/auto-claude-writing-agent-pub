# Think Aloud 规范

> **适用范围**：所有关键决策时刻
> **核心价值**：透明化思考过程，避免AI黑盒

---

## 使用场景

### 必须使用 Think Aloud 的时刻

- 判断任务类型时
- 选择工作流程时
- 做关键决策时（选题、风格、方向）
- 遇到问题不确定时
- 发现潜在风险时

---

## 格式规范

### 标准格式

```markdown
【Think Aloud】
当前任务：[简洁描述]
判断：[我的分析和判断]
流程：[接下来的执行计划]
预计：[预期结果或需要注意的点]
```

---

## 示例

### 任务类型判断

```markdown
【Think Aloud】
当前任务：用户要求修改已有文章
判断：这是任务类型C（修改已有文章）
流程：读取原文 → 理解需求 → 修改 → 审校
预计：30-60分钟完成
```

### 选题决策

```markdown
【Think Aloud】
当前任务：确定文章选题
判断：基于用户需求，有3个可能方向
流程：提供3-4个选题方案，说明各自利弊
预计：需要用户确认后才能继续
```

### 风险提示

```markdown
【Think Aloud】
当前任务：用户要求跳过调研步骤
判断：这可能影响内容准确性
流程：提醒风险 → 等待用户确认
预计：如果用户坚持，将按用户要求执行
```

---

## 注意事项

- ✅ 简洁明了，不需要冗长解释
- ✅ 逻辑清晰，让用户理解你的判断
- ✅ 诚实面对不确定，主动说明
- ❌ 不要事后诸葛亮（先执行再说Think Aloud）
