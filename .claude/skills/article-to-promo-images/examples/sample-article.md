# Claude Code Skills 入门教程

## 一次配置，永久省心

Claude Code Skills 是一个革命性的功能，它让你可以将专业知识和工作流程封装成可复用的技能包。只需一次配置，Claude 就会自动在合适的时机调用这些技能，无需重复描述背景信息。

## 核心价值

- **自动调用** - 根据任务类型自动触发相应技能
- **知识封装** - 将专业知识打包成结构化文档
- **团队共享** - 通过 Git 仓库统一团队标准
- **Token 节省** - 渐进式加载机制节省 90%+ Token

## 快速开始

### 第一步：创建技能目录

在项目根目录下创建 `.claude/skills/` 目录：

```
my-project/
└── .claude/
    └── skills/
        └── my-skill/
            └── SKILL.md
```

### 第二步：编写 SKILL.md

```markdown
# 我的技能

## 何时使用
当用户需要 X 功能时自动触发。

## 执行流程
1. 分析需求
2. 执行操作
3. 返回结果
```

### 第三步：开始使用

重新打开对话或重启 Claude Code，技能将自动生效。

## 技能 vs 传统提示词

| 对比项 | 传统提示词 | Skills |
|--------|-----------|--------|
| 初始化成本 | 每次都需要描述 | 一次配置永久有效 |
| Token 消耗 | 每次完整加载 | 渐进式按需加载 |
| 团队协作 | 难以统一标准 | Git 仓库统一管理 |
| 知识沉淀 | 散落在对话中 | 结构化文档存档 |

## 进阶技巧

### 渐进式披露

将 SKILL.md 保持简洁，详细信息放在链接文件中：

```markdown
# 主技能

→ [详细文档](details.md)
→ [示例代码](examples.md)
```

### 参数化技能

使用模板变量让技能更灵活：

```markdown
输入参数：
- framework: React/Vue/Angular
- language: TypeScript/JavaScript
```

## 常见问题

**Q: 技能支持哪些编程语言？**
A: 任何语言！Skills 是语言无关的。

**Q: 可以在团队中共享技能吗？**
A: 可以，将 `.claude/skills/` 提交到 Git 仓库即可。

**Q: 技能会占用很多 Token 吗？**
A: 不会，渐进式加载机制确保只加载需要的内容。
