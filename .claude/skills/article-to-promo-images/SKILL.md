# Article to Promo Images

自动将文章内容转换为精美的宣传图片HTML。

## 何时使用

当用户请求将文章转换为宣传图、配图、海报等可视化内容时自动触发：

- "把这篇文章做成宣传图"
- "为这篇教程生成配图"
- "帮我制作文章封面图"
- "生成X张分享图片"

## 输入参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `source` | string | ✅ | 本地MD路径 或 文章URL |
| `count` | number | ❌ | 图片数量（默认智能计算） |
| `style` | string | ❌ | 设计风格：cyber/minimal/warm/nature（默认cyber） |
| `output` | string | ❌ | 输出路径（默认当前目录/promo-images.html） |

## 执行流程

1. **读取内容** - 解析本地MD文件或抓取URL
2. **智能分析** - 提取标题、摘要、关键点、结构
3. **选择模板** - 根据内容类型匹配图片模板
4. **生成HTML** - 动态填充模板，生成独立HTML文件
5. **返回结果** - 提供文件路径和使用说明

## 输出示例

```
✓ 已生成宣传图HTML：./promo-images.html
包含4张图片：
  01. 封面图 - Claude Code Skills 教程系列
  02. 要点图 - 三大核心价值
  03. 对比图 - 痛点与解决方案
  04. 路线图 - 课程学习路径

在浏览器中打开即可预览和下载PNG图片
```

## 图片类型说明

| 类型 | 用途 | 提取逻辑 |
|------|------|----------|
| `cover` | 封面图 | 标题 + 副标题 + 核心标签 |
| `key-points` | 要点图 | 3-5个关键要点列表 |
| `comparison` | 对比图 | Before/After、问题/方案 |
| `roadmap` | 路线图 | 章节、步骤、学习路径 |
| `quote` | 金句图 | 精彩语句、核心观点 |
