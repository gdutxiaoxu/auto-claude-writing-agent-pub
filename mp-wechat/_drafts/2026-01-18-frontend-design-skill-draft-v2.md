## 01｜先搞懂：什么是 Skills？

简单说，Skills 就是一个包含 `SKILL.md` 文件的文件夹。

这个文件里写的，是告诉 AI「在特定场景下该怎么做」的指令集。

你可以这么理解：

> 大模型就像一个拥有全世界菜谱的顶级厨师。
>
> 普通指令"给我做顿饭"，厨师为了保险、或者受限于自身品味，会给你做一盘西红柿炒鸡蛋——能吃，但很普通。
>
> 使用 Skills，等同于额外强调："你是米其林三星主厨，请用分子料理技术，做一道展现'深海孤独感'的创意菜"，并且详细给出什么是分子料理、什么是深海孤独感。
>
> 厨师就会调动毕生所学，给你做出一道艺术品。

`frontend-design` skill 的工作方式正是如此。

## 02｜这个 skill 好在哪？

`frontend-design` 是 Anthropic 官方出品的 skill，专门用来提升大模型的前端审美能力。

它的核心指令可以概括为：**拒绝通用，拥抱独特**。

具体来说，它强调五个维度：

### 字体
❌ 避免：Inter、Roboto、Arial 这些"安全字体"
✅ 推荐：选择有性格、独特的字体组合

### 色彩
❌ 避免：紫色渐变、均匀分布的配色
✅ 推荐：大胆的主色调 + 尖锐的点缀色

### 动效
❌ 避免：零散的微交互
✅ 推荐：精心编排的页面加载动画（staggered reveals）

### 布局
❌ 避免：对称、可预测的网格
✅ 推荐：非对称、重叠、对角线流动、破格元素

### 细节
❌ 避免：纯色背景
✅ 推荐：渐变网格、噪点纹理、几何图案、戏剧化阴影

**关键原则**：每个设计都应该独一无二，绝不要收敛到"常见选择"。

## 03｜手把手教程：3 步搞定

真的只需要 3 步，大概 2 分钟。

### 步骤一：安装 skill

打开终端，执行这条命令：

```bash
npx skills-installer install @anthropics/claude-code/frontend-design --client claude-code
```

**支持的工具**：
- Claude Code：用上面的命令
- Codex：把 `--client` 改为 `codex`
- Cursor：用 `npx skills-installer install @anthropics/claude-code/frontend-design --local --client cursor`

**注意**：你需要先安装 Node.js。

### 步骤二：重启工具

关闭并重新打开你的 AI 编程工具（Claude Code / Codex / Cursor）。

### 步骤三：开始使用

接下来，当你需要做前端设计时，只需要在提示词里加一句：

> "使用 frontend-design skill 来完成前端设计"

然后尽情描述你的需求就好。

举个例子：

> 设计一个 AI 产品的数据分析 Dashboard。左侧是导航栏，顶部放四个数据卡片显示今日概览（用户数、调用次数、收入、增长率），中间是 7 天趋势折线图，右侧放最近的 API 调用记录列表。**使用 frontend-design skill 来完成前端设计**。

就这么简单。

## 04｜使用技巧

### 新项目 vs 老项目

- **新项目**：skill 会不安装任何依赖，快速完成纯 HTML/CSS/JS
- **老项目**：显式告诉它你的技术栈（React、Vue、Tailwind 等），它会按你的要求来

### 什么时候用？

简单的 CRUD 后台、内部工具，用不用 skill 差别不大。

但当你做：
- 产品官网
- 落地页
- 展示型页面
- 需要惊艳效果的场景

这时候，frontend-design skill 就能派上用场。

### 进阶：定制你的品牌调性

你可以在原版 skill 的基础上，加入自己的品味：

- 主色调
- 字体偏好
- 圆角风格
- 阴影参数
- 按钮风格

修改后的 skill 会让每次生成都符合你的品牌调性，效果更稳定。

## 05｜原理：为什么 400 tokens 这么管用？

一个 skill 文件也就 400 tokens 左右，为什么能带来这么大的改变？

核心在于：**它不是教 AI "怎么做"，而是教 AI "怎么选"**。

大模型本身已经"见过"无数优秀设计，它缺的不是知识，而是**判断标准**。

`frontend-design` skill 做的，就是把这个判断标准写清楚：

- 什么样的字体选择是有意义的
- 什么样的配色是有张力的
- 什么样的布局是令人难忘的

有了这些标准，AI 就能调用它已有的知识库，做出正确的选择。

**不是注入新能力，而是激活已有能力。**
