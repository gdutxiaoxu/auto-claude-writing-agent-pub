# 配图 Prompt（简化版）

## 配图计划（3-4张）

### 1. 问题场景图
**用途**：开篇展示重复解释规则的痛点

**Prompt：**
```
minimalist illustration of a person repeatedly explaining the same rules to an AI robot, expression of frustration, clean tech aesthetic, soft colors, white background, --style raw --v 6 --ar 16:9
```

---

### 2. Skills 概念图
**用途**：展示"写一次，反复用"的核心概念

**Prompt：**
```
clean illustration showing a single rule document being reused multiple times, a document icon with arrows pointing to multiple AI executions, concept of "write once, use forever", minimalist style, soft blue colors, white background, --style raw --v 6 --ar 16:9
```

---

### 3. 文件结构示例
**用途**：展示 Skill 文件的简单结构

**Prompt：**
```
clean code editor screenshot showing a simple file structure, a folder named "commit-helper" containing a single SKILL.md file, the file is open showing clean markdown code with YAML frontmatter, minimal interface, professional IDE aesthetic, --style raw --v 6 --ar 16:9
```

---

### 4. 五大好处图
**用途**：总结 Skills 的核心价值

**Prompt：**
```
clean infographic showing 5 benefits of a system, numbered icons with simple labels: 1. No repetition, 2. Team consistency, 3. Auto-trigger, 4. Permission control, 5. Complex rules, minimalist design, soft colors, white background, --style raw --v 6 --ar 16:9
```
